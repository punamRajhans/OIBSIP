# 🌡️ Temperature Converter

## 📌 Project Overview

The Temperature Converter is a simple web application developed using **HTML5, CSS3, and JavaScript**. It allows users to convert temperature values between **Celsius (°C), Fahrenheit (°F), and Kelvin (K)**. The application validates user input and displays converted values in a clean and user-friendly interface.

---

## 🚀 Features

- Convert temperature between:
  - Celsius (°C)
  - Fahrenheit (°F)
  - Kelvin (K)
- Input validation for numeric values.
- Error message for invalid input.
- Absolute zero validation.
- Displays all converted temperature values together.
- Reset button to clear all inputs and results.
- Attractive glassmorphism UI with a sky background video.
- Responsive and easy-to-use interface.

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension (if not already installed).
4. Right-click on `temp.html`.
5. Select **Open with Live Server**.
6. Enter a temperature value, select the unit, and click **Convert**.

---

## 📷 Output

The application provides:
- A temperature input field.
- Unit selection dropdown.
- Convert and Reset buttons.
- Converted values displayed in Celsius, Fahrenheit, and Kelvin.
- Error messages for invalid inputs and temperatures below absolute zero.
